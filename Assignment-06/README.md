## Aim
Convert an object to JSON text, convert JSON text back to an object, and catch invalid JSON.

## Questions / Tasks
1. Create an object with name Rohan and marks 70 and 80 in an array, convert it to JSON text with JSON.stringify and print the text.
2. Store the text {"city":"Pune","pin":411001} in a variable, convert it to an object with JSON.parse and print the city.
3. Store the text {name: Rohan} in a string variable, use try and catch to call JSON.parse on it, and print Invalid JSON in the catch block.
