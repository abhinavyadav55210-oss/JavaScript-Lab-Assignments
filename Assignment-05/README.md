## Aim
Create an array, read its items, use forEach and filter, and read a value from an array inside an array.

## Questions / Tasks
1. Store marks 72, 85, 64 and 90 in an array named marks, then print the number of items and the first mark.
2. Store Maths, Science and English in an array, then use forEach to print each subject.
3. Store marks 72, 85, 45 and 90 in an array, then use filter to make a new array with only marks of 60 or more and print the new array.
4. Store [1, 2, 3] and [4, 5, 6] inside an array named grid, then print the number in row 2 and column 3.
