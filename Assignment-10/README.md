## Aim
Create an object, read and change its properties, and take values out of an array and an object with destructuring.

## Questions / Tasks
1. Create student with name Rohan, roll 12 and marks 78, print the name, change marks to 81 and print marks again.
2. Store Maths, Science and English in an array, use array destructuring to put the first two subjects into first and second, and print each one on its own line.
3. Create student with name Rohan, roll 12 and marks 81, use object destructuring to take out name and roll, and print each one on its own line.
