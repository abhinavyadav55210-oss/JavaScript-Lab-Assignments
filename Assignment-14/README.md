## Aim
Run code after a delay with setTimeout, cancel a timer, and repeat code with setInterval.

## Questions / Tasks
1. Print Start, schedule Timer done with setTimeout and a delay of 0, then print End. Run it and note the order.
2. Schedule Not shown with setTimeout and a delay of 1000 milliseconds, keep its id in a variable, cancel it with clearTimeout, and print Cancelled.
3. Use setInterval to print Tick followed by a space and the count every 200 milliseconds, and stop it with clearInterval when the count reaches 3.
