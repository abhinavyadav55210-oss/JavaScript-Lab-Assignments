## Aim
Use reduce, some, every and map on arrays, and keep the original array unchanged.

## Questions / Tasks
1. Store prices 120, 45 and 300 in an array, use reduce starting from 0 to find the total, and print the total.
2. Store marks 72, 85, 30 and 90 in an array, use some to print whether any mark is below 40, and use every to print whether all marks are 35 or more.
3. Store marks 72, 85, 64 and 90 in an array, use map to make a new array where every mark is 5 more, print the new array, then print the original array.
