## Aim

## Questions / Tasks
1. Create a function greet that takes a name and returns Hello, followed by a comma, a space and the name. Print greet for Asha.
2. Create an arrow function square that returns a number multiplied by itself. Print square(6).
3. Create billWithTax(amount, taxRate) that returns amount plus amount times taxRate, where taxRate is 0.18 when not given. Print billWithTax for 100 with no tax rate given.
