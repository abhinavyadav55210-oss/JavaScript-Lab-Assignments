## Aim
Use extends to make a child class, write a method that checks a value, and place one object inside another.

## Questions / Tasks
1. Create a class Person, whose method greet returns Hi, I am followed by the name, and a class Teacher that extends Person and adds a subject. Create Anita, who teaches Maths, and print her greeting.
2. Create a class Locker (pin 1234) and a method checkPin that returns true if its number equals the pin, otherwise false. Create a Locker and print checkPin(1111) and checkPin(1234), one per line.
3. Create classes Engine (stores a power) and Car (holds an Engine made from its power, and method start returns Car starts with, the power and HP). Create a Car with power 150 and print start().
