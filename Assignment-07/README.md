## Aim
Create objects with a constructor function and with an ES6 class, and add a method through the prototype.

## Questions / Tasks
1. Create a constructor function Student that takes name and marks and saves them on the object. Create a student named Asha with marks 88 and print her name and marks, one on each line.
2. Create an ES6 class Book that takes title and pages, and a summary method that returns the title, has, the page count and pages, with spaces. Create Algorithms with 320 pages and print its summary.
3. Write a constructor function Student that stores name and marks, add a method result to Student.prototype returning Pass for marks of 40 or more and Fail otherwise, then create Asha with marks 88 and print her result.
