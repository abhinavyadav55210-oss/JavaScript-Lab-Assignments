## Aim
Change a page with a click, check form values in code, save text in local storage, and build a small quiz.

## Questions / Tasks
1. Create a page with a heading Welcome and a button Change text. When clicked, the heading changes to Button clicked.
2. Create validateForm(name) that returns a list of errors and adds Name is required when name is empty. Print it for Asha, then for an empty name.
3. Create a page with a text box and Save button, where clicking Save stores the text in localStorage under key note. When the page opens, the saved text is shown in the box.
4. Create a page with question What is 2 + 3?, radio buttons 4, 5 and 6, and a Check answer button. Show Correct when 5 is chosen, and Try again otherwise.
